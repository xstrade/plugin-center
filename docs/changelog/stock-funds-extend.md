# 股票基金管家更新日志

<!-- #region latest -->
## v4.0.5 — 2026-08-14

### 新增

- 新增多股看盘模式，支持分时、5 日、日 K、周 K、月 K 以及 5、15、30、60 分钟 K 线集中查看。
- 看盘模式支持每行显示 2 个或 3 个图表，并自动记住布局选择。

### 优化

- 优化图表懒加载、数据缓存和尺寸自适应，提升多图浏览性能。
- 优化分组栏横向滚动，分组编辑和模式切换入口固定在右侧。
- 新增 `NEW` 提示，帮助用户发现多股看盘入口。

### 修复

- 修复股票详情页关闭后，插件弹窗没有恢复列表宽度的问题。
- 修复股票、基金切换时弹窗宽度异常的问题。
- 基金列表移除已停用的预估涨跌幅，统一按净值展示。
