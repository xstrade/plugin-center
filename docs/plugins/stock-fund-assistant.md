# 股票基金助手 - 盯盘助手

股票基金助手是一款面向日常盯盘场景的浏览器扩展，可以在浏览器工具栏的小窗口中查看自选股票、ETF、可转债和基金行情，并管理分组、持仓收益和股价提醒。

- 当前商店版本：**3.8.0**
- 下一版本：**Manifest V3 升级版（开发中）**
- Manifest V3 验证环境：Chrome 120+

::: warning 请认准产品名称
“股票基金助手”和“股票基金管家”是两个独立扩展，商店 ID、版本和本地数据均不通用。需要保留股票基金助手旧数据时，请更新原“股票基金助手”，不要通过安装“股票基金管家”代替升级。
:::

## 快速开始

1. 从上方对应的浏览器商店安装扩展。
2. 将扩展固定到浏览器工具栏，点击图标打开主面板。
3. 使用底部的“股票/基金”按钮切换自选类型。
4. 在底部搜索框输入名称或代码，选择搜索结果后加入当前分组。
5. 点击“编辑自选”填写持仓信息，或点击“分组”管理不同自选列表。

## 股票自选

股票面板底部的搜索框支持输入股票、场内基金、可转债名称或代码。选择结果后，插件会先校验行情，再将其加入当前分组。

列表可以展示：

- 市价、涨跌额、涨跌幅和换手率。
- 持仓价、持仓数和持仓金额。
- 当天收益、收益率和总收益。

点击股票名称左侧的展开按钮，可以查看证券代码、东方财富详情、股吧、F10、分时、日 K、周 K、月 K 和股价提醒。

## 基金自选

切换到基金面板后，在“输入基金名或代码”的搜索框中选择基金。列表可以展示基金估值、持仓价、持有金额、持有份额、涨跌幅和收益数据。

展开基金后，可以进入天天基金详情、基金吧，查看历史走势和基金持仓明细。基金净值存在发布时间差异，请以基金公司最终公布的数据为准。

## 分组管理

1. 点击主面板底部的“分组”。
2. 选择已有分组，或进入编辑状态新增、重命名和排序分组。
3. 新增股票或基金时，数据会保存到当前选中的对应分组。

每个分组最多保存 50 个自选项目。删除分组会同时删除该分组内的自选，请先确认其中的数据不再需要。

股票分组与基金分组独立管理，切换股票、基金面板时会恢复各自最后一次使用的分组。

## 编辑持仓和查看收益

点击“编辑自选”进入编辑状态：

- 股票可以填写持仓价、持仓数和是否今日建仓。
- 基金可以填写持仓价和持有份额。
- 自选支持拖动排序、置顶和删除。

完成编辑后，点击底部“当日盈亏”可以查看股票、基金及合计数据，包括当日收益、当日收益率、总收益、总收益率和持仓金额。

## 行情、大盘和数据中心

- 主面板顶部默认显示大盘指数，点击指数可查看详细走势。
- 点击“更多”可以展开更多指数，并在“添加/编辑”中调整指数列表及顺序。
- 点击股票详情中的“查看大图”可以进入独立行情页面。
- 点击底部“数据中心”可以查看更丰富的市场数据。

## 设置股价提醒

1. 展开目标股票。
2. 切换到“股价提醒”。
3. 填写阈值和通知文案。
4. 打开对应提醒右侧的开关。

支持以下条件：

- 股价涨到指定价格。
- 股价跌到指定价格。
- 日涨幅超过指定百分比。
- 日跌幅超过指定百分比。

提醒与股票关联，不跟随分组切换。启用提醒后，即使目标股票不在当前展示分组，插件也会继续获取提醒所需行情。

::: tip 收不到通知时
请检查浏览器和操作系统是否允许浏览器发送通知，并确认提醒开关、阈值和交易时段。相同提醒条件在短时间内不会重复通知。
:::

## 个性化设置

点击主面板右下角齿轮按钮进入设置页，可以调整：

- 扩展角标关闭、显示日收益或显示日收益率。
- 股票和基金列表需要展示的字段。
- 是否显示顶部大盘。
- 表格字号：默认、中、小。
- 深色或浅色主题。
- 面板透明度和灰度。
- Chrome、Edge 等浏览器中的扩展快捷键。
- 交易日 14:40 提醒。

设置保存在当前浏览器的扩展存储中，重新打开扩展后仍会沿用。

## 数据备份与恢复

### 导出和导入文件

在“设置 → 数据管理”中：

- 点击“导出备份”下载当前业务数据。
- 点击“导入备份”选择此前导出的 JSON 文件。

导入会覆盖当前股票、基金、分组、持仓、提醒和相关设置。导入前，插件会先为当前数据创建保护备份。

### 使用备份记录

在设置页切换到“备份记录”：

1. 点击“手动备份”保存当前状态。
2. 点击“下载”把指定备份保存到电脑。
3. 点击“恢复”并确认，用该备份覆盖当前数据。
4. 普通备份可以删除，升级保护备份不能删除。

普通备份滚动保留最近 5 份。升级、导入和恢复前产生的保护快照会独立保留。

## 从 Manifest V2 升级到 V3 {#upgrade-v3}

下一版本将把后台运行机制升级到 Manifest V3，并把旧版后台 `localStorage` 中的业务数据迁移到新的本地数据库。

### 正确升级方式

1. 从原商店直接更新“股票基金助手”，确保扩展 ID 不变。
2. 不要先卸载旧版本，不要清除扩展数据。
3. 更新后首次启动时，等待“正在检查并保护用户数据”完成。
4. 迁移成功后，到“设置 → 备份记录”确认升级保护备份存在。
5. 核对股票和基金分组、组内自选、持仓、提醒和界面设置。

自动迁移包含：

- 股票分组、自选、持仓价、持仓数量和今日建仓状态。
- 基金分组、自选、持仓价和持有份额。
- 大盘指数、股价提醒、活动分组和界面设置。

迁移开始前会先保存并校验原始数据快照。迁移中断或浏览器重启后，会从已经保存的阶段继续处理；迁移成功后也不会再次读取旧数据覆盖后续修改。

::: danger 不要卸载后重装
卸载扩展通常会同时删除浏览器保存的扩展数据。需要保留旧数据时，请直接更新原“股票基金助手”。安装“股票基金管家”不会迁移“股票基金助手”的数据。
:::

### 迁移失败怎么办

如果页面提示“数据迁移暂未完成”：

1. 保留原扩展和浏览器数据，不要清空存储。
2. 点击“重试”再次执行固定迁移流程。
3. 如页面提供“导出已校验的升级前业务备份”，请先下载保存。
4. 保留错误信息并联系开发者处理。

## 常见问题

### 为什么行情没有立即更新？

请检查网络连接并稍候刷新。非交易时段、停牌证券、基金净值尚未公布或行情服务异常，都可能造成数据暂时不变。

### 删除分组会发生什么？

删除分组会同时删除其中的自选记录。股价提醒独立于分组，但删除股票时，对应提醒会被停用。

### 恢复备份后可以撤销吗？

恢复前插件会保护当前状态，可以在“备份记录”中选择恢复前生成的保护备份再次恢复。

### Chrome、Edge 和 Firefox 的版本为什么不同？

各浏览器商店的审核进度不同，因此同一时间可能展示不同版本。Manifest V3 升级版当前按 Chrome 120+ 环境开发和验证，其他商店以上架页面为准。
