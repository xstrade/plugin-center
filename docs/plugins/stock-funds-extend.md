# 股票基金管家

股票基金管家是一款用于查看自选股票、ETF、可转债和基金行情的浏览器扩展，支持列表盯盘、多股图表看盘、持仓收益与分组管理。

- 最新版本：**4.0.5**
- 更新日期：**2026-08-14**
- 支持平台：Chrome、Edge、Firefox

## 主要功能

- 查看自选股票、ETF、可转债和基金行情。
- 管理自选分组、持仓信息和收益数据。
- 使用多股看盘同时查看分时、5 日和多个 K 线周期。
- 配置列表展示列及看盘布局。

## 安装方法

1. 打开对应浏览器的下载入口。
2. 点击“添加至浏览器”或“安装”。
3. 安装完成后，从浏览器工具栏打开插件。
