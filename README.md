# XSTrade Project Center

XSTrade 的公开项目与工具发布中心，用于集中展示项目介绍、下载方式、使用说明和更新记录。

当前站点收录：

- 股票基金管家
- 股票基金助手

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
npm run docs:preview
```

## 发布

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。

站点地址：https://xstrade.github.io/plugin-center/
